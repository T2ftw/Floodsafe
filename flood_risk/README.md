# Member 1 — Flood Risk Assessment

## Overview

This module estimates flood risk across the Nalasopara study area using
elevation, slope, and rainfall data.

## Method

Elevation + Slope + Rainfall
→ Risk Calculation
→ 0–100 Risk Score
→ Risk Category

## Risk Categories

- Safe
- Moderate
- High
- Critical

## Current Output

- 84 spatial grid cells
- Normalized flood-risk score from 0–100
- Four flood-risk categories
- GIS-based flood-risk visualization

## Study Area

Nalasopara, Maharashtra, India.
